# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| `0.1.x` (main) | Yes |
| older / forks | Best effort |

## Reporting a vulnerability

**Do not** open a public GitHub issue for security problems.

Please report privately via one of:

1. GitHub **Security Advisories** → *Report a vulnerability* on this repository (preferred if enabled)
2. Email the maintainers listed in the GitHub org / profile for this repo

Include:

- Description of the issue
- Steps to reproduce
- Affected version / commit
- Impact assessment (if known)
- Whether you plan a public disclosure timeline

We aim to acknowledge reports within **7 days** and to provide a remediation plan when validated.

## Scope notes

- NFCM is **local-first**. Issues that require network services are out of core scope unless a contributor adds optional networking.
- Mock inference is intentionally non-production; do not treat mock outputs as trusted medical/legal advice.
- Please avoid submitting exploit PoCs that target third-party systems.

## Safe harbor

We will not pursue legal action against good-faith security research that follows this policy, stays within the scope of this repository, and avoids privacy violations or service disruption.
