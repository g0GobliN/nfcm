# Support

## Where to get help

| Need | Where |
|------|--------|
| Bug report | GitHub Issues on this repository |
| Feature / research idea | GitHub Issues (`enhancement` / `research`) |
| Usage questions | GitHub Discussions (if enabled) or Issues |
| Security | [SECURITY.md](SECURITY.md) only |
| Docs | [`docs/`](docs/) |

## What to include in a bug report

- OS and version
- Rust / Node versions (`rustc -V`, `node -v`)
- Steps to reproduce
- Expected vs actual behavior
- Logs from Runtime Console / Dev Tools if relevant

## Response expectations

This is an early open-source project. Maintainers respond as bandwidth allows. Clear, reproducible reports get help faster.

## Commercial / enterprise support

Not offered by default. If you need a support contract, open a Discussion or contact maintainers listed on the GitHub org.
